## Best use of *this* hardware (done / doable)

1. **Reliable control** — rules + 120B for chat; lights, TV, scenes, weather, multi-command, delayed jobs  
2. **Station UI** — not a chatbot: power, brightness, TV, activity, busy lock  
3. **Memory** — session + name profile + audit  
4. **No extra cloud lock-in** — HA is the hand; OpenRouter is rented language only  
5. **Next without new boxes:** HA automations (sunset), more plugs/sensors you already buy for HA, presence via phone app + HA
